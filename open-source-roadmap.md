# 12-Month Open-Source Roadmap

## Months 1–3
- Validate requirements with teachers and learners.
- Expand APIs, tests and child-data safeguards.
- Publish contribution templates and issue roadmap.

## Months 4–6
- Release a stable API and open-source database adapter.
- Add French and Malian-language content metadata.
- Publish low-cost deployment guides and licence review.

## Months 7–9
- Integrate the API with Glide as one independent client.
- Run a consent-based pilot with anonymized measurement.
- Publish aggregate indicators and invite contributors.

## Months 10–12
- Improve offline and low-bandwidth support.
- Add interoperable content import and export.
- Document replication and publish a sustainability plan.
