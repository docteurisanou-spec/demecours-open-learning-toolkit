# Security and Responsible Data

Report vulnerabilities privately to **contact@demecours.com**. Do not open a public issue containing exploit details or personal data.

This repository must never contain child names, contact details, precise locations, raw learner profiles, assessment histories, passwords, tokens or production database exports. The prototype publishes aggregate counters only. A production deployment requires access controls, encryption, retention limits, consent where applicable, and a child-rights and data-protection review.
