# Contributing

- Keep the toolkit usable independently from Glide or any proprietary platform.
- Never commit personal data, student records, credentials or API keys.
- Use anonymized or synthetic examples.
- Document the source and licence of educational content.
- Prefer accessible, low-bandwidth and mobile-friendly designs.

Run `pytest` before opening a pull request. Code contributions are MIT-licensed; educational content must be compatible with CC BY 4.0.
